# 左侧快捷入口

默认在思源左侧栏底部增加两个独立的原生风格按钮：

- 集市：直接打开“已下载 → 插件”界面
- 设置：直接打开思源原生设置

插件不会隐藏或移动思源原来的入口。禁用或卸载本插件后，新增按钮会自动移除。

## 设计

- 默认位于左侧栏底部，可通过右键菜单分别移动到左上、左下、右上、右下、底部左侧或底部右侧
- 移动位置由思源保存，重启后自动恢复
- 不创建额外窗口，通过思源前端 API 打开现有的集市和设置界面
- 不受“插件抽屉”位于左侧或右侧的影响
- 支持桌面端和桌面浏览器端

## 安装

1. 完全退出思源。
2. 将手动安装包解压到：

   ```text
   {工作空间}/data/plugins/
   ```

3. 确认最终路径是：

   ```text
   {工作空间}/data/plugins/siyuan-plugin-left-shortcuts/plugin.json
   ```

4. 重启思源，在“集市 → 已下载 → 插件”中启用“左侧快捷入口”。

## 兼容性

当前版本 v0.1.4 针对思源 3.7.3 验证，最低支持思源 3.7.0。

插件使用思源原生 Dock 注册和前端设置 API。禁用或卸载后只会移除新增入口，不会修改或删除思源原生入口。
